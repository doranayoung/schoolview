# 학교 정보 입력 가이드 (교사·학생회용)

스쿨뷰에 학교 정보를 올리는 방법입니다. 프로그래밍을 몰라도 **입력 도우미** 화면에서 칸을 채우면 됩니다.

## 한눈에 보기

1. 스쿨뷰 화면 맨 아래 **"교사·학생회: 학교 정보 입력 도우미"**를 누릅니다.
2. **새로 시작**을 누르거나, 이미 올라가 있는 학교라면 **등록된 학교 불러오기**에서 고릅니다.
3. 기본 정보 → 선택과목 → 동아리 → Q&A 순서로 입력합니다.
4. **미리보기**에서 학생에게 보일 화면을 확인합니다.
5. **확인·내보내기**에서 점검 결과와 확인란을 체크하고 JSON 파일을 내려받습니다.
6. 파일을 스쿨뷰 운영자에게 보냅니다. 운영자가 확인한 뒤 올리면 학교 목록에 나타납니다.

작성 중인 내용은 지금 쓰는 기기(브라우저)에만 저장됩니다. 다른 컴퓨터에서 이어서 하려면 JSON 파일로 내려받은 뒤, 그 컴퓨터에서 **JSON 파일 불러오기**를 누르세요.

## 입력하기 전에 꼭 지켜 주세요

스쿨뷰는 중·고등학생이 쓰는 서비스라, 아래 원칙을 지킨 정보만 올립니다.

| 원칙 | 이렇게 해 주세요 |
|---|---|
| 학교 확인 | 담당 교사 또는 학생회가 확인한 정보만 올립니다. |
| 개인정보 최소화 | 학생·교사의 이름, 전화번호, 이메일, 사진을 넣지 않습니다. 답변자는 "2학년 재학생"처럼 학년만 적습니다. |
| 평가 자료 금지 | 시험 문제, 기출, 수행평가 답안·모범 답안을 넣지 않습니다. 평가는 "지필·발표·보고서" 같은 **유형**만 고릅니다. |
| 비교·순위 금지 | "지역 최고", "○○고보다 낫다" 같은 비교·순위 표현을 쓰지 않습니다. |

입력 도우미는 전화번호·이메일·"기출" 같은 표현이 보이면 경고를 띄웁니다. 그래도 최종 판단은 사람이 해 주세요.

## 항목 설명

### 기본 정보

| 항목 | 설명 | 예 |
|---|---|---|
| 학교 이름 | 정식 이름 | 한빛고등학교 |
| 학교 ID | 영어 소문자·숫자·하이픈. 파일 이름과 주소에 쓰입니다. 한 번 정하면 바꾸지 않는 게 좋습니다. | busan-hanbit |
| 지역 | 시·구 정도까지 | 부산 해운대구 |
| 학교 유형 | 일반고, 특성화고 등 | 일반고 |
| 학년당 학급 수 | 숫자 | 8 |
| 한 줄 소개 | 학교를 한 문장으로 | 과학·정보 선택과목이 다양한 학교예요. |
| 학교 특색 | 한 줄에 하나씩 | 2학년부터 과목별 이동수업 |
| 정보 출처 | 어디서 확인한 정보인지 | 학교알리미, 학교 제공 (교육과정부) |

### 선택과목

| 항목 | 설명 |
|---|---|
| 과목 이름 · 구분 | 공통 / 일반선택 / 진로선택 / 융합선택 |
| 주로 듣는 학년 · 학점 | 학교 교육과정 편성표 기준 |
| 수업 방식 | 강의식, 토론, 프로젝트, 실습 등에서 고르기 |
| 평가 유형 | 지필, 서술형, 발표, 보고서, 실기 등에서 고르기 |
| 교실 | 이동수업 교실 (선택) |
| 선배 한마디 | 학생회·교사가 확인한 한 줄 소개 (선택) |
| 키워드 | 진로 탐색에 쓰입니다. 화면에 보이는 진로 탐색 키워드(코딩, AI, 의학, 교육 등)를 넣어야 진로 탐색 결과에 나옵니다. |

### 동아리

| 항목 | 설명 |
|---|---|
| 동아리 ID | 자동으로 만들어집니다. 다른 동아리와 겹치면 안 됩니다. |
| 모집 일정 | 시작일·마감일을 넣으면 "모집 중 · D-3"처럼 표시되고, 동아리 모집 모아보기에 마감 순으로 나옵니다. |
| 사전 설문 문항 | 지원 전에 학생이 미리 답해 볼 질문. 한 줄에 한 문항. |
| 신청서 주소 | 동아리가 쓰는 구글 설문 등의 주소. 아래 "신청서 연결하기"를 참고하세요. |

### 재학생 Q&A

학생회·담당 교사가 확인한 답변만 넣습니다. 확인한 사람(학생회 / 담당 교사)을 꼭 고릅니다.

## 동아리 신청서 연결하기 (구글 설문)

스쿨뷰는 지원자 정보를 저장하지 않습니다. 학생은 스쿨뷰에서 사전 설문 답변을 쓰고, **동아리 신청서에서 학번·이름을 적어 제출**합니다.

1. 구글 설문에 사전 설문 문항을 스쿨뷰와 **같은 순서**로 만들고, 학번·이름 문항은 그 뒤에 둡니다.
2. 구글 설문 편집 화면 오른쪽 위 ⋮ → **미리 채워진 링크 가져오기**를 누릅니다.
3. 사전 설문 문항마다 아무 값(1, 2, 3…)이나 넣고 **링크 가져오기 → 링크 복사**를 누릅니다.
4. 입력 도우미의 **신청서 주소** 칸에 붙여넣습니다. 주소와 entry 번호가 자동으로 나뉘어 들어갑니다.
5. "사전 설문 N문항과 entry N개가 맞아요"가 보이면 완료입니다. **미리보기**에서 직접 눌러 확인해 보세요.

구글 설문이 아닌 신청서(네이버 폼 등)는 주소만 넣으면 됩니다. 이때는 신청서를 열면서 답변이 복사되어, 학생이 붙여넣기만 하면 됩니다.

## 운영자에게 보내기

- 내려받은 `학교ID.json` 파일을 운영자에게 보냅니다.
- GitHub를 쓸 수 있다면 [src/data/schools](https://github.com/doranayoung/schoolview/tree/main/src/data/schools) 폴더에 파일을 올리는 Pull Request를 보내도 됩니다.
- 정보가 바뀌면 **등록된 학교 불러오기 → 수정 → 다시 내려받기** 후 같은 방법으로 보냅니다.
